# Icono del repositorio

Un único SVG, `core.svg`, usado en la cabecera del README y como icono de la carpeta del repositorio.

- Glifo: dos etapas enlazadas y una flecha de ejecución, por la cadena de CI/CD.
- Formato: 64×64, `rx=16`, fondo navy con degradado (`#07131e` → `#0e2a47`), borde cian sólido de 2 px (`#38bdf8`) y glifo blanco relleno (`#f8fafc`) en una caja de 44×44 centrada. El icono lleva su propio fondo, así que se lee igual sobre GitHub claro y oscuro.
